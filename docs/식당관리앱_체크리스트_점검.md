점검일: 2026-10-29 · 대상: 현재 `main` 코드 (입고·거래처·재고·레시피·원가·결산·근무표)

표시 기준

| 표시 | 뜻 |
|---|---|
| ✅ | 구현됨 — 지금 앱에서 바로 쓸 수 있음 |
| 🟡 | 일부만 — 비슷한 기능은 있지만 체크리스트 수준에는 못 미침 |
| ❌ | 없음 — 추가 구현 대상 (아래 "2부"에 정리) |

## 7. 주문·판매·할인·환불 — 전 항목 ❌

주문번호·영업일, 메뉴·옵션별 수량, 판매 채널, 할인·쿠폰·서비스, 할인 부담 주체, 전체/일부 취소, 부분 환불, 취소 사유·처리자, 결제수단, 외상 회수, 주문 정정·이력, 메뉴·시간대·요일·채널별 판매량, 총매출~순매출 구분 — **모두 없음**.
→ POS가 이미 하는 일이 대부분이라, 직접 만들기보다 **POS 매출 자료를 가져오는 방식**(2부 B-1)을 권장합니다.

## 8. POS·배달 플랫폼·결제 정산 — 전 항목 ❌

POS 가져올 데이터, 연동 실패 대비, 카드사·간편결제 입금 대조, 배달앱별 수수료·광고비·배달비, 플랫폼/매장 부담 할인, 예상 vs 실제 입금, 입금 예정·실제일, 정산 차이 기록, 현금 시재 시작·마감, 현금 과부족 사유 — **모두 없음**.

# 2부. 빠진 기능 — 추가 구현 목록

> 순서는 "지금 있는 기능을 더 정확하게 만드는 것 → 새 영역 추가" 순으로, 효과 대비 작업량을 기준으로 묶었습니다.
> 각 묶음은 대화로 "A-1 구현해줘"처럼 요청하면 바로 작업할 수 있게 정리했습니다.

## A. 지금 기능 보강 (작업량 작음~중간, 효과 큼)

**A-1. 거래처 정보 보강**
- 담당자·전화번호·계좌(은행/계좌번호/예금주)·메모 칸 추가
- 결제 조건: 즉시결제 / 월말 마감 후 N일 / 매주 ○요일 등 → **지급 예정일 자동 계산**
- 거래처 목록에 "이번 주 지급 예정", "지급일 지남(연체)" 표시 + 홈 카드 알림
- 계좌 정보는 결제 화면처럼 결산 비밀번호로 한 번 더 잠그기

**A-2. 재료(물품) 기준정보**
- 분류(육류·채소·수산·양념·포장재 등), 규격, 보관 방법(냉장·냉동·실온), 보관 위치
- 과세/면세 구분 (부가세 신고 때 매입 구분용)
- 기본 거래처·대체 거래처 지정
- **품목별 최소 재고량** 설정 → 재고 부족 알림을 "마이너스"가 아니라 "최소량 이하"로 판단

**A-3. 판매가·레시피 이력 보존**
- 판매가 변경 시 이전 가격·적용 시작일 보존 (가격 인상 전후 원가율 비교 가능)
- 레시피 저장 시 변경 사유·적용일 기록, 과거 버전 보관
- 월말마다 메뉴별 원가 스냅샷 저장 → "지난달 대비 원가 변동" 비교

**A-4. 메뉴 원가 정밀화**
- 원재료별 수율(손질 후 남는 비율, 예: 대파 85%) 입력 → 원가에 자동 반영
- 메뉴 분류(전골·식사·사이드·주류), 판매 상태(판매중·품절·중단)
- 홀/포장 원가 따로 보기 (포장 용기·봉투 등 포장재 묶음을 포장 원가에만 추가)
- 기본 반찬 세트(김치·나물 등)를 "공통 제공 묶음"으로 만들어 메뉴별 1인분 반찬 원가 자동 포함
- 추가 옵션(사리·만두 추가 등) 가격·원가

**A-5. 입고 보강**
- 운반비·할인 칸 별도 입력 (원가에는 비율로 배분할지 선택)
- 반품·교환·파손·누락 기록 (사유 포함, 미지급금에서 차감)
- 입고 담당자 이름, 검수 결과(정상/불량), 유통기한(선택 입력)
- 세금계산서·영수증·이체 확인증 사진 첨부 (결제 기록에도 증빙 사진)

**A-6. 재고 보강**
- 사용 사유 구분: 정상 사용 / 직원 식사 / 시식 / 서비스 제공
- 실사 일정(매주·매월) 설정 + "실사할 때 됐어요" 홈 카드
- 실사 결과 이전 회차와 비교 화면, 조정 사유 필수 입력·확인자 이름
- 사용량을 금액으로 환산 → **"실제 사용 원가"** 계산 (입고액과 구분)

**A-7. 알림 실제 발송**
- 이미 있는 알림 설정 화면에 카카오 알림톡 또는 문자 발송 연결
- 대상: 재고 부족·지급 예정/연체·원가율 경고·실사 일정·급여일

**A-8. 기록 보존·변경 이력**
- 삭제 대신 "취소" 처리(목록에서 숨기되 기록은 남김) — 명세표·결제·사용·폐기·실사
- 모든 저장/수정/취소에 "언제·어느 기기/누가·무엇을" 변경 기록 남기기, 화면에서 조회

## B. 새 영역 추가 (작업량 큼)

**B-1. 매출 가져오기 (POS 엑셀 업로드)** ← 손익 자동화의 출발점
- 사용 중인 POS에서 일/메뉴별 매출 엑셀을 내려받아 업로드 → 날짜·메뉴·수량·금액·할인·취소·결제수단 저장
- 업로드 전 미리보기(형식·중복 날짜 확인)
- 영업일 기준(예: 새벽 2시 이전 매출은 전날로) 설정
- 이후 자동 연동(POS API)은 POS 업체 지원 여부 확인 후 결정

**B-2. 판매 연동 재고 자동 차감 + 메뉴별 실적**
- B-1 판매 수량 × 레시피 → 이론 사용량 자동 계산, 실사와 비교해 **로스율** 산출
- 메뉴별 판매량·매출·원가·이익 순위, 예상 이익 vs 실제

**B-3. 배달앱·카드 정산 대조**
- 배민·쿠팡이츠·요기요 정산 내역 업로드 → 매출·수수료·광고비·배달비·할인 부담 구분
- 카드사별 매출 vs 입금액, 입금 예정일 vs 실제 입금일, 차이 기록

**B-4. 일일 마감**
- 시작 시재·마감 시재 입력, 결제수단별 매출 확인
- 현금 과부족 금액·사유·확인자, 마감 담당자 기록
- 마감 후 수정은 결산 비밀번호 필요

**B-5. 운영비(지출) 관리**
- 지출 입력: 날짜·금액·항목(임대료·관리비·공과금·통신비·소모품·수리비·광고비·수수료 등)·결제수단·담당자·영수증 사진
- 정기 지출(임대료·관리비 등) 등록 → 다음 지급일 알림
- 월별·항목별 예산, 예산 대비 실제·초과 알림
- 월말에 결산의 "일반경비"를 이 기록으로 **자동 채우기**

**B-6. 직원·급여**
- 직원 정보: 직무(주방·홀)·고용 형태(정규·파트)·입사일·시급/월급·퇴사일
- 근무표 O/△ 기준 근무시간 설정 → 월 예상 급여 자동 계산 (주휴수당·야간·연장 기준은 노무사 확인 후 반영)
- 실제 지급액·지급일·지급 상태 기록, 매장별 인건비 집계 → 결산 "인건비" 자동 채우기
- 급여 화면은 결산 비밀번호로 잠금

**B-7. 자동 손익·현금흐름 보고서**
- B-1·B-5·B-6·입고 자료로 월 손익 자동 계산: 순매출 → 매출총이익(순매출 − 재료 원가) → 영업이익, 산식을 화면에 표시
- 발생 기준(입고·사용 기준) vs 현금 기준(실제 결제·입금 기준) 나란히 보기
- 전월·전년 동월·목표 대비 비교, **3개 매장 합산·비교 화면**
- 보고서 엑셀·PDF 내보내기

**B-8. 사용자 역할·권한**
- 매장 PIN 하나 대신 사람별 PIN: 대표 / 매니저 / 주방 / 홀
- 역할별 메뉴 노출 (예: 주방 = 입고·재고·레시피만, 매니저 = 결산·급여 제외 전부)
- 퇴사자 PIN 중지, PIN 분실 시 대표가 재설정
- A-8 변경 이력에 "누가"가 정확히 남게 됨

**B-9. 백업 복원**
- 내려받은 CSV를 다시 올려 특정 기간/표를 복원 (덮어쓰기 전 미리보기)
- 월 1회 자동 백업 파일 보관, 보관 기간 규정

**B-10. 발주 관리** (필요 시)
- 발주서 작성(품목·수량·납품 희망일) → 카톡/문자로 거래처 전송
- 입고 시 발주 수량 vs 실제 수량 비교, 부분 입고·미입고 잔량 표시
- 재주문 알림에서 바로 발주서 만들기

## C. 사장님이 먼저 정할 운영 기준 (📋, 개발 전 결정 필요)

1. 영업일 기준 시각 (자정 넘은 매출을 어느 날로 볼지)
2. 판매 채널 범위 (홀·포장·배달·단체 예약 중 어디까지 따로 볼지)

| 알림 설정 | 메뉴에서 숨김 | 문자·카톡 발송이 안 돼서 켜고 꺼도 달라지는 게 없음 (홈 화면 알림 카드는 그대로) |
| 거래처별 결제액 + 거래처 물품 입고액 + 소비 패턴 분석 | "거래처 리포트" 하나로 합침 | 셋 다 기간별 입고·결제 금액을 다른 모양으로 보여주는 화면 |
| 재고 관리의 "사용량" 입력, 품목별 사용 리포트, 재고 부족 카드 | 매일 사용량을 입력하지 않으면 숨김 → 재고는 "월 1회 실사 + 폐기"만 | 사용량을 안 넣으면 재고 숫자가 실제와 맞지 않아 알림도 믿을 수 없음 |
| 재주문 알림 (메뉴) | 메뉴에서 빼고 홈 카드만 유지 | 정기 배송·감으로 주문하는 매장에는 화면까지는 불필요 |
| 폐기/손실 리포트 | 폐기를 꾸준히 기록하면 유지, 아니면 숨김 | 기록이 없으면 빈 화면 |
| 사용법 물어보기 | 유지(선택) | 유지 비용이 거의 없음 |

## 새로 넣을 것 — 꼭 필요한 6개
| 순서 | 기능 | 추가 입력 부담 | 이유 |
|---|---|---|---|
| 1 | 거래처 결제 조건·전화번호 → 지급 예정일 표시 (A-1 간단판) | 거래처당 1회 | 지금 가장 많이 쓰는 미지급금 기능의 마무리 |
| 2 | 거래처·매장 간 단가 비교 (D-1·D-2) | 없음 | 이미 있는 입고 자료로 바로 절감 포인트 확인 |
| 3 | 판매가 변경 이력 + 판매가 시뮬레이터 (A-3 일부·D-3) | 없음 | 가격 인상 판단 근거 |
| 4 | 원산지 표시판 관리 (E-1) | 품목당 1회 | 법적 의무, 과태료 예방 |
| 5 | 직원 보건증 만료 알림 (E-2) | 직원당 1회 | 법적 의무, 근무표 직원명에 날짜만 추가 |
| 6 | 주간 경영 브리핑 (H-2) | 없음 | 3개 매장을 한 번에 확인 (발송 수단 결정 필요) |

## 넣지 않을 것
POS·배달 정산, 일일 마감·시재, 급여 계산, 직원별 권한·역할, 발주 관리, 예산, 세트·옵션 원가, 유통기한·선입선출, 자동 손익 보고서 — POS·세무사·급여 대행이 이미 하거나 매일 입력 부담이 커서 제외.
조건부: 단체 예약 장부(해율 3층 예약을 종이로 관리 중이면 검토), 의제매입세액공제 집계(세무사가 처리하면 불필요).
