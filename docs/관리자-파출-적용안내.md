# 메인 관리자 · 매니저 분리 + 파출 관리 적용 안내

이번 변경을 실제 앱에 적용하는 순서입니다. **순서대로** 진행하세요.

## 1. 새 앱 배포 (Vercel)
- 이 브랜치를 main에 합치면 Vercel이 자동으로 배포합니다.
- Vercel 환경 변수는 **새로 넣을 것이 없습니다.** 다만 `STORE_AUTH_SECRET`은 이제 파출 주민번호 암호화에도 쓰므로 **절대 바꾸지 마세요.**

## 2. Supabase에서 SQL 한 번 실행
1. Supabase → SQL Editor → New query
2. `supabase/roles.sql` 내용을 전부 붙여넣고 **Run**
3. 맨 아래 결과 표에 표마다 정책이 하나씩 보이면 정상입니다.
   - `admin only` = 관리자 전용 (거래처 결제·시작 잔액, 결산, 레시피·원가, 직원 근무표, 사업자 정보)
   - `store members or admin` = 매니저는 자기 매장, 관리자는 전부

> `roles.sql`은 여러 번 실행해도 안전합니다. 이미 실행한 뒤에 기능이 추가되면(예: 홀/주방 포지션) **한 번 더 실행**하면 새 칸만 추가됩니다.
>
> 문제가 생기면 `supabase/roles-rollback.sql`을 실행하면 이전 상태(매장별 잠금)로 돌아갑니다. 자료는 지워지지 않습니다.

## 3. 메인 관리자 비밀번호 정하기
1. 앱 첫 화면 맨 아래 **[🔑 메인 관리자 로그인]**
2. 처음이면 비밀번호(숫자 6~12자리)를 두 번 입력 → 바로 들어가집니다.
3. ⚠️ 배포 후 **사장님이 가장 먼저** 설정하세요. 처음 들어간 사람이 비밀번호를 정하게 됩니다.
4. 변경: 메인 메뉴 맨 아래 **설정 · 기타 → 🔑 관리자 비밀번호 변경**
5. 잊어버렸을 때: Supabase → Table Editor → `admin_settings` → `pin_hash` 칸을 비우면(NULL) 처음처럼 다시 정할 수 있습니다.

## 4. 세무 출력용 사업자 정보 넣기
- 관리자 → **파출 세무 출력** → "지불인(사업자) 정보 → 고치기"에서 매장마다 상호·대표·사업자번호·주소를 한 번 저장하세요.

## 바뀐 점 요약
| 구분 | 매니저 (매장 비밀번호 4자리, 지금과 같음) | 메인 관리자 |
|---|---|---|
| 들어가는 곳 | 그 매장 1곳 | 4개 매장 (위쪽 탭/왼쪽 선택칸으로 전환) |
| 메뉴 | 거래명세표 등록 · 실재고 조사 · 파출 관리 | 지금 메뉴 전부 + 인력·파출 |
| 거래처 결제·미수금·결산·원가 | 볼 수 없음 (서버에서도 막음) | 전부 |
| 파출 송금 상태 | 볼 수만 있음 | 송금완료 체크·취소 |
| 송금완료된 파출 근무 | 고치거나 지울 수 없음 | 고칠 수 있음 |
| 관리자가 결제 처리한 명세표 | 고치거나 지울 수 없음 | 고칠 수 있음 |
| 매장 비밀번호 변경 | 불가 | 설정 → 매장(매니저) 비밀번호 변경 |

## 참고
- 파출 근무를 등록할 때 **홀/주방**을 꼭 체크해야 저장돼요. 명부에 평소 포지션이 저장돼 다음부터는 자동으로 체크됩니다. 파출 관리 화면에서 홀/주방별로 걸러 보고 포지션별 합계를 볼 수 있어요.
- 기존에 매장 비밀번호로 열어둔 기기는 이제 **매니저 화면**으로 보입니다. 사장님은 관리자 로그인으로 다시 들어오세요.
- 매장운영결산은 관리자로 들어오면 결산 비밀번호를 다시 묻지 않습니다.
- 일당 15만 원 이하는 소득세 0원으로 계산합니다. 한 달 8일 이상 근무자는 ⚠️로 표시됩니다(국민연금·건강보험 확인 대상 — 세무사와 확인하세요).

## 통합 매출·결산 (추가)
1. Supabase → SQL Editor에서 `supabase/sales.sql`을 한 번 실행하세요 (일매출 표, 관리자 전용).
2. 메뉴 **거래처 · 정산 → 🧮 통합 매출·결산** (메인 화면 4개 매장 현황 아래에도 바로가기)
   - **통합 결산**: 매장운영결산을 기간(시작 월~끝 월)을 정해 4개 매장 합산, **월별/년별** 합산 표, 결산 미입력 달 표시, 엑셀
   - **일매출**: OKPOS 연결 전까지 직접 입력 (총매출·카드·현금·기타·객수). 일별 표의 칸을 눌러 입력·수정, 월별/년별 합산

## 매니저 메뉴 5개 + 전달사항 (추가)
1. Supabase → SQL Editor에서 `supabase/manager-menu.sql`을 한 번 실행하세요.
   - 매니저도 자기 매장의 거래처 결제 내역·장부 시작 잔액을 **볼 수** 있게 바뀌어요 (입력·수정·삭제는 관리자만)
   - 전달사항 표가 만들어져요
2. 매니저 메뉴: 입고 입력 · 실재고 조사 · 거래처 관리 · 단가 추이 조회 · 파출 관리
   - 거래처 관리는 관리자와 같은 장부(미지급금·결제 내역)를 보지만, 결제 입력·장부 시작 설정·일괄 결제·삭제 버튼은 안 보여요
3. 전달사항: 관리자 → 설정·기타 → 📢 매니저 전달사항 (메인 화면 현황에도 바로가기). 매장을 골라 보내면 매니저 메인 화면 맨 위에 뜨고, 매니저가 [확인했어요](+답장)를 누르면 관리자 화면에 표시돼요

## 파출 경로 + 근무자 메모 (추가)
1. **배포 전에** Supabase → SQL Editor에서 `supabase/dispatch-sources.sql`을 실행하세요. (새 앱은 근무 기록의 경로 칸을 읽기 때문에, 먼저 실행하지 않으면 파출 화면이 열리지 않아요)
2. 파출 근무 등록 때 **경로(파출사무소·당근 등)**를 꼭 골라야 저장돼요. 4개 매장이 같은 목록을 쓰고, 등록 중에 [+ 새 경로]로 바로 추가할 수 있어요
3. 예전에 입력한 근무는 '경로 미입력'으로 보여요. 목록의 [수정]으로 넣어주세요
4. 파출 관리 → [🏢 경로 관리]: 관리자는 이름·연락처·메모 수정과 숨기기, 매니저는 목록 보기·전화 걸기·추가
5. 근무자 메모(근무 태도·숙련도)는 인력 명부 → [정보 수정]에서 쓰고, 근무 등록·명부·고정 파출 화면에 보여요
